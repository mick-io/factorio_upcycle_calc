How Values Are Calculated

Show Calculation Details

The planner models an upcycling loop. Items below the target quality are recycled and fed back into crafting.

Machine ratio per quality is solved from a steady-state loop: craft by quality -> recycle below target -> return 25% of items -> repeat.

Recycler throughput (items/s each) = Recycler Input Per Cycle / Recycle Cycle Time.

Recyclers Needed = ceil(Items Sent to Recyclers / Recycler Capacity per Machine).

Machine counts are always rounded up so the displayed plan is buildable in-game.
